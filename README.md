# The NFL Family

NFL fan site built with Astro and deployed on Cloudflare Pages.

## 🏈 Features

- Game news and updates
- Division & Conference standings
- Game calendar and kickoff times
- Community discussions

## 🚀 Development

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```

## 🌐 Deployment

Auto-deployed to Cloudflare Pages on every push to `feature/staging` branch.
